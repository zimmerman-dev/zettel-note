## Emoji Legend
A consistent set of semantic emojis for use in notes.  
Emojis are **functional markers**, not decoration.
### 📖 Core Usage
-   **🔹 Heading** → Start of a concept or section
-   **📌 Pinned Fact** → Fundamental truth / law you want to burn in
-   **⚠️ Caution** → Subtle trap, common mistake, or risky behavior
-   **❗ Warning** → Urgent danger, critical attention needed
-   **⛔ Do Not Do** → Absolute don’t, anti-pattern
----------
### 💡 Knowledge Markers
-   **💡 Reminder** → Extra tidbit, helpful aside
-   **📦 Idea** → Summarized thought / packaged conclusion
-   **🔑 Key Insight** → Big takeaway or “aha”
-   **📝 Note** → General comment or clarification
----------
### ✅ / ❌ Evaluators
-   **✅ Check** → Confirmed truth, reliable standard
-   _(Optional: you might add ❌ Wrong / Misconception if you like symmetry — but your current set already works)_
----------
### 📍 Spatial / Directional
-   **📍 Location** → Specific place, reference point
-   **➡️ ⬅️ ⬆️ ⬇️** → Movement, flow, direction markers (great for diagrams or explaining code flow)
----------
